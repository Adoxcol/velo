Browser Extension

One-click downloads from Chrome and Edge

The extension hands downloads to Velo, finds videos on pages (HLS, DASH and media files) and adds “Download with Velo” to the right-click menu. It talks to Velo through the browser's native messaging, never an open network port.

  1. Open chrome://extensions or edge://extensions and turn on Developer mode.
  2. Click Load unpacked and choose the extension folder from the Velo source.
  3. The extension ID should be dmdcijgljocjdmafenflenjhdjhenokc. Run install.ps1 once so the browser can reach Velo.

Downloads of common file types in Chrome and Edge are handed to Velo automatically. See Browser Extension in the sidebar to set it up.

Video grabber

The extension detects HLS (.m3u8) and DASH (.mpd) streams and media files while a video plays. Velo picks the best quality and merges audio and video with ffmpeg. Encrypted (DRM) and live streams, and sites that protect their videos (such as YouTube), are not supported.
