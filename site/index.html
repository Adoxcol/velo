# Install with one line (Linux, macOS):
curl -fsSL https://velo.adoxcol.com/install.sh | sh
# …or with a package manager:

Installation, checksums and command guide →

Linux and macOS currently support standalone terminal downloads. The desktop interface, browser extension connection, queue and scheduler are Windows features. A Linux desktop app is planned.

Regular file downloads need no extra tools. Video pages need yt-dlp and ffmpeg; YouTube also needs a supported JavaScript runtime such as Deno. These tools are installed separately.

Why Velo

A desktop app for your Windows downloads

Big files, slow servers, flaky Wi-Fi and links that expire.

Up to 32 connections

Every file downloads in parts at the same time. Servers that slow down each connection automatically get more.

Pause and resume

Stop anytime and carry on later, even after closing Velo or restarting your PC.

Survives network drops

Velo waits for the connection to come back and resumes by itself. Your PC stays awake until it's done.

Video grabber

Finds HLS and DASH streams while a video plays and saves the best quality, with audio and video together.

Refresh expired links

Link stopped working halfway? Paste a fresh one and the same file continues where it stopped.

Queue and scheduler

Set how many run at once, reorder the queue, pick download hours, and sleep or shut down when finished.

Windows setup

Up and running in a minute

No account, no sign-up, no administrator rights.

1

Install Velo

Run the installer. It sets Velo up for your Windows account and adds it to the Start menu. Or use the portable zip.

2

Add the extension

Get Velo Download Manager for Chrome, Edge or Brave, or for Firefox. The installer already connects your browsers to Velo.

3

Download as usual

Click download links like always. Velo shows the file and folder, then gets it done faster.

What Velo doesn't do

Velo does not bypass DRM or access restrictions. Supported YouTube, Facebook and X video pages use optional yt-dlp, ffmpeg and Deno tools. Availability depends on the site and extractor; live streams are not supported.

FAQ

Questions

Does Velo work on Linux and macOS?

Yes: veloctl get <url> downloads directly in your terminal, without the desktop app. Intel/AMD and ARM64 packages are available above. The Linux desktop app is planned; browser integration remains Windows-only.

Is Velo really free?

Yes. Velo is open source under the MIT license, with no ads, no paid tier and no tracking.

Does Velo collect any data?

Velo has no analytics or tracking. Downloads contact the sites you choose; the Windows app contacts GitHub to check for updates. The extension sends download information to the local Velo app. Read the privacy policy.

Why does Windows warn about an unknown publisher?

The installer isn't code-signed yet, so SmartScreen doesn't recognise it. Choose "More info" and then "Run anyway". The source is public, and every release lists its SHA-256 so you can check the file.

How does Velo update?

The installed Windows app checks GitHub, verifies the installer checksum and updates while idle. Portable Windows copies and Linux/macOS CLI users download the new package manually. Keep optional video tools up to date separately.

Does it work with Firefox?

On Windows, yes—and with Chrome, Edge and Brave. Linux/macOS CLI builds do not connect to browser extensions yet. Install the add-on from Firefox Add-ons, then allow Velo on all sites when it asks, so it can find videos and catch downloads.

Can I use it without installing?

Yes. Unzip the portable version anywhere, even a USB stick, and run velo.exe. Settings stay in a folder next to it.
