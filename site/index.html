Why Velo

Built for the downloads browsers get wrong

Big files, slow servers, flaky Wi-Fi and links that expire.

Up to 32 connections

Every file downloads in parts at the same time. Servers that slow down each connection automatically get more.

Pause and resume

Stop anytime and carry on later, even after closing Velo or restarting your PC.

Survives network drops

Velo waits for the connection to come back and resumes by itself. Your PC stays awake until it's done.

Video grabber

Finds HLS and DASH streams while a video plays and saves the best quality, with audio and video together.

Refresh expired links

Link stopped working halfway? Paste a fresh one and the same file continues where it stopped.

Queue and scheduler

Set how many run at once, reorder the queue, pick download hours, and sleep or shut down when finished.

Get started

Up and running in a minute

No account, no sign-up, no administrator rights.

1

Install Velo

Run the installer. It sets Velo up for your Windows account and adds it to the Start menu. Or use the portable zip.

2

Add the extension

Add Velo to Chrome, Edge, Brave or Firefox. The installer already connects your browsers to Velo.

3

Download as usual

Click download links like always. Velo shows the file and folder, then gets it done faster.

What Velo doesn't do

Velo downloads what websites openly serve. It doesn't get around DRM, encryption or other protections, so protected streaming services and sites like YouTube aren't supported.

FAQ

Questions

Is Velo really free?

Yes. Velo is open source under the MIT license, with no ads, no paid tier and no tracking.

Does Velo collect any data?

No. The extension only talks to the Velo app on your own PC, and Velo only contacts GitHub to check for updates. Read the privacy policy.

Why does Windows warn about an unknown publisher?

The installer isn't code-signed yet, so SmartScreen doesn't recognise it. Choose "More info" and then "Run anyway". The source is public, and every release lists its SHA-256 so you can check the file.

How does Velo update?

Velo checks GitHub for new versions, verifies the download's SHA-256 and installs it when nothing is downloading. You can turn this off in Settings.

Does it work with Firefox?

Yes, and with Chrome, Edge and Brave. In Firefox, allow Velo on all sites when the add-on asks, so it can find videos and catch downloads.

Can I use it without installing?

Yes. Unzip the portable version anywhere, even a USB stick, and run velo.exe. Settings stay in a folder next to it.
